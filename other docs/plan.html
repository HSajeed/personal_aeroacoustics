NASA SDT fan/OGV broadband noise: 7-day plan

One repo that shows two things: the basic theory implemented and validated correctly, and real rig data handled with its uncertainty stated. Thursday 5 November to Wednesday 11 November 2026.

In scope

  • Annular-duct mode library
  • Strip-theory broadband model (PN1-type, ACAT1 Part II)
  • Comparison with NASA SDT at approach, 54-vane and 26-vane OGVs
  • Uncertainty budget and 2-page note

Out of scope this week

  • Interstage liners (second sprint)
  • JHTDB channel DNS
  • Microphone-array mode detection
  • LES or any new CFD

Unverified until Day 1. Nothing below assumes these.

  • The SDT figures (length scales, wake spectra, predicted-against-measured power) are legible enough to digitise. Only extracted text has been read so far.
  • OGV-only exhaust spectra are readable for both the 54-vane and 26-vane cases.
  • Which hot-wire velocity component maps to blade-normal upwash for the vane stagger.
  • Annulus area (about 2.4 ft²) and mean axial Mach number at the OGV were derived, not read. The OGV table column alignment needs checking against the PDF.

Day by day

A day is closed only when its exit gate passes. If a gate fails, fix it before starting the next day’s work.

Day 1Thu 5 Nov

Data gate

  • Upload the four PDFs: TM-2003-212329 (wake flow), TM-2002-211798 (noise prediction), TM-2005-211681 (geometry, rotor-alone), Fernandes Part II.
  • Digitise length scales, wake spectra and predicted-against-measured power figures.
  • Build the geometry file from the tables: vane count, chord, sweep, stagger, camber, thickness.
  • Log provenance and uncertainty for every number. Settle the upwash component mapping. Verify annulus area and table alignment.

Day 2Fri 6 Nov

Annular-duct mode solver

  • Hard-wall annular eigenmodes for azimuthal order m and radial order n.
  • Cut-on frequencies and the mode-count map. Unit tests.
Exit gateComputed eigenvalues match the Bessel-function root condition, and the cut-on frequencies are correct for the SDT annulus.
Expected resultmodes.py with passing tests, and a validation plot of eigenvalues and the cut-on map.

Technical note only

  • No code edits. Write the problem, model, validation, results and limits.
Exit gateThe 2-page note is complete and every number in it traces to a figure or to the provenance log.
Expected resultA 2-page technical note, ready to send with the repo link.

If you fall behind

Cut in this order: the Amiet upgrade (Sears is only correct at very low frequency, and the two differ by about 3 to 4 dB downstream in the ACAT1 benchmark), then the swept-vane case, then the stagger sensitivity.

Never cut: the validation tests, the baseline comparison, or the uncertainty budget.

Success criteria

  • All validation tests pass.
  • Baseline spectral shape and peak frequency compared with data, dB offset reported. NASA’s own model under-predicted levels, so an offset is acceptable if shape and trend hold.
  • Vane-count trend reported against measurement.
  • Uncertainty budget covers digitisation, hot-wire corrections, rotor-noise contamination and the decay assumption.
  • Figures regenerate from the raw digitised data with one command.
Data: NASA Glenn Source Diagnostic Test reports. Model: ACAT1 benchmark Part II (Guérin et al.). All SDT inputs are digitised from published figures and carry stated uncertainty.
