# NASA SDT Digitisation — Day 1 Data Package

**Source repository:** `/mnt/s/projects/UHBR`

**Purpose:** Digitised NASA Source Diagnostic Test (SDT) data from three PDF reports and one Fernandes paper, with full provenance, uncertainty, and cross-checks. No vision AI was used to read plots; all data were extracted by deterministic vector/morphology methods.

**Gate status:** **PASS** — 54-vane and 26-vane measured exhaust spectra digitised, with geometry, provenance and uncertainty. See `data/qa/data_quality.md`.

## Limitations (recorded in `data/qa/qa_summary.json` and `data/provenance/provenance.md`)

- NASA p14 is an image-only plate; values come from 3 px raster bins with 0.12 dB k=1 uncertainty.
- 26–35 % of 3 px bins required short-gap interpolation (TL: 109/308; BL: 82/301; TR: 64/282); flagged in CSVs.
- Fernandes Fig. 18(c) is dB/Hz; NASA Fig. 9 is dB; only spectral shape is compared.
- Figs. 26–28 are source-limited 1-bit raster scans (~500 px wide). Curves, symbols and dotted log-grids merge into single connected components; no numeric values are claimed. See `data/qa/raster_figure_screening.csv`.
- The report does not quote a single OGV leading-edge station; annulus area is evaluated at x = 3–6 in bracket.

## Caveats

- All CSVs carry a `source_*` column giving the source PDF page, report page, and coordinate-derived y-pt / x-pt for auditing.
- Uncertainty estimates are k=1 (one standard deviation) unless noted otherwise.
- "dB" and "dB/Hz" are different units; the NASA/Fernandes comparison normalises each to its own 2–8 kHz median before computing shape metrics (Pearson r, RMS).
- Figs. 26–28 are documented as screened, not numerically digitised, rather than inventing values.
- The mean axial Mach (0.3029 ± 0.0044) uses static-property continuity with Table 3 approach conditions; a total-density shortcut gives 0.2868 (under-predicts as expected).
